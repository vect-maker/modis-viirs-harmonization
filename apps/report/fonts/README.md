# Report fonts

Liberation Serif 2.1.5 is bundled in regular, bold, italic, and bold italic styles.
The report recipes pass `--font-path fonts` to Typst, so no system-wide font
installation is required. New Computer Modern is provided by Typst itself.

Source: https://github.com/liberationfonts/liberation-fonts/releases/tag/2.1.5

Official binary archive:
https://github.com/liberationfonts/liberation-fonts/files/7261482/liberation-fonts-ttf-2.1.5.tar.gz
